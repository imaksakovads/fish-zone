# SEO-план: появление fish-zone.ru в поисковиках

> **Для Hermes:** Использовать навык subagent-driven-development для выполнения по задачам.

**Goal:** Приблизить сайт fish-zone.ru к появлению и росту в поисковиках (Яндекс, Google) — закрыть технические и контентные пробелы SEO.
**Architecture:** Продвижение в 3 слоях: (1) техническое SEO, (2) контентная глубина, (3) внутренняя перелинковка + вебмастер.
**Tech Stack:** static GitHub Pages, build.py (Python), schema.org JSON-LD, Яндекс.Вебмастер, Google Search Console.

## План (по приоритету)

### Этап 1: Техническое SEO (быстро, высокий эффект)

#### Task 1: Подключить Google Search Console
**Цель:** Google видит сайт, sitemap, индексацию.
**Файлы:** `.well-known/` или HTML-файл верификации.
**Шаги:**
1. Добавить сайт в Google Search Console (https://search.google.com/search-console).
2. Верифицировать (DNS TXT или HTML-файл).
3. Отправить `sitemap.xml`.
4. Проверить индексацию, исправить ошибки.

#### Task 2: Добавить `Organization` + `WebSite` JSON-LD на главную
**Цель:** поисковик понимает сущность сайта.
**Файлы:** `templates/blog-index.html`, `build.py`.
**Действие:** проверить, что на главной есть `Organization` (уже есть) и добавить `WebSite` с `SearchAction`.

#### Task 3: Проверить скорость и мобильную версию
**Файлы:** тестирование (PageSpeed Insights, Lighthouse).
**Действие:** прогнать URL, исправить: lazy-load картинок, minify CSS, кэш. (Часть уже есть — `loading="lazy"`.)

#### Task 4: Оптимизировать изображения (alt, размеры)
**Цель:** image SEO + скорость.
**Файлы:** `content/*.md`, `static/images/`.
**Действие:** убедиться, что все `<img>` имеют осмысленный `alt`; добавить `width`/`height` для CLS.

### Этап 2: Контентная глубина (главный рычаг)

#### Task 5: Добить контент-план (20 статей уже, добавить ещё)
**Цель:** закрыть семантическое ядро (631 маска приоритета A).
**Файлы:** `content/*.md` (генерация через пайплайн).
**Действие:** продолжать генерацию статей по плану `_Семантика/SEO-контент-план-20-статей.md`, после него — новые темы. **Пилотная статья перед каждой серией** (валидатор + критик).

#### Task 6: Страницы-хабы категорий
**Цель:** внутренняя перелинковка и семантическая структура.
**Файлы:** `build.py`, `templates/`.
**Действие:** создать страницы `/tekhniki/`, `/ryby/`, `/snasti/`, `/primanki/`, `/osnastka/` — списки статей по категории с перелинковкой.

#### Task 7: Блок «Похожие статьи» в каждой статье
**Цель:** увеличить внутренние ссылки (сейчас только prev/next).
**Файлы:** `build.py`, `templates/blog-post.html`.
**Действие:** в `pick_related()` уже есть логика — вывести 3-4 похожих статьи с якорным текстом.

### Этап 3: Доверие и вебмастер

#### Task 8: Страница «О блоге» + «Контакты»
**Цель:** EEAT-сигнал (опыт, авторитет), контакт для обратной связи.
**Файлы:** `content/o-bloge.md`, `content/kontakty.md`, `templates/`.
**Действие:** добавить 2 статические страницы с `Person`/`Organization` разметкой.

#### Task 9: Авторство (Author JSON-LD)
**Цель:** Google понимает автора (EEAT).
**Файлы:** `build.py`.
**Действие:** проверить, что `BlogPosting` содержит `author` → `Person` с именем и ссылкой.

#### Task 10: Яндекс.Вебмастер — добавить https-версию, регион, переобход
**Цель:** полнота в Яндексе.
**Действие:** в Вебмастере добавить `https://fish-zone.ru`, указать регион «Россия», запросить переобход после обновлений.
