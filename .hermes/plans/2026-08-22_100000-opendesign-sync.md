# Подключение OpenDesign и синхронизация UI/стилей fish-zone

**Goal:** Сверить эталонный дизайн из OpenDesign (главная + статья) с реальным сайтом fish-zone и перенести недостающие/изменённые элементы в рабочие шаблоны.

**Architecture:** OpenDesign хранит эталонные HTML-файлы дизайна. Наш сайт строится из `templates/*.html` через `build.py`. Нужно перенести изменения из эталонов OpenDesign в шаблоны (CSS-токены, структуру, новые элементы вроде `hero-emblem`), сохранив работоспособность сборки.

**Tech Stack:** HTML, CSS (OKLch-токены), Python build.py, GitHub Pages.

## Подход

1. **Сверить эталон главной** `fish-zone-blog.html` с нашим `blog-index.html`
   - Найти новые CSS-токены, классы, секции (hero-emblem и др.)
   - Найти различия в карточках (OpenDesign vs наша генерация в build.py)
2. **Сверить эталон статьи** `article-lovit-schuku-spinning.html` с нашим `blog-post.html`
3. **Скопировать недостающие ассеты** (logo-spinning-pro.png, favicon-512.png) в `static/`
4. **Внести изменения в шаблоны** (CSS + структура), сохранив плейсхолдеры `{{...}}`
5. **Пересобрать** (`python3 build.py && python3 gen_sitemap.py`), проверить
6. **Закоммитить и задеплоить**
